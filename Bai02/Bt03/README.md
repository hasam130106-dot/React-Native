# BÀI THỰC HÀNH 03 – ProductApp

## 1. Giới thiệu ứng dụng

**Tên ứng dụng:** ProductApp  
**Tên cửa hàng:** HVS STORE  
**Công nghệ:** React Native và Expo.

Ứng dụng giới thiệu và bán thiết bị công nghệ với 6 sản phẩm, hiển thị hình ảnh, tên, giá và mô tả.

## 3. Các chức năng chính

- Hiển thị 6 sản phẩm công nghệ.
- Hiển thị hình ảnh, tên, giá và mô tả.
- Sử dụng FlatList để kết xuất danh sách.
- Sử dụng ProductCard nhận dữ liệu qua Props.

## 4. Cấu trúc code

- App.js: Xây dựng giao diện chính và danh sách sản phẩm.
- ProductCard.js: Hiển thị thông tin từng sản phẩm.
